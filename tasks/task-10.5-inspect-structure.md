# Task 10.5 — Inspect project structure

## Objective

Inspect and document the project's directory structure.

## Steps

1. List the project root directory (`ls -la`).
2. List the `src/` directory.
3. Display the full visual tree of the project.

## Acceptance criteria

- [ ] Project root and `src/` contents are listed.
- [ ] Full visual tree is displayed.

## Verification

```bash
ls -la
ls -la src
tree .
```
